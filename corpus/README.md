# 教材语料目录

老师（LLM）出题与讲解的**真实依据**就来自这里。往本目录放 `.md` / `.txt` 文件即可，会被 `src/agent/retriever.js` 按小节（Markdown 标题）切分并检索。

## 支持

- 格式：`.md`、`.txt`
- 层级：最多递归 3 层子目录
- 切分：按 Markdown 标题切小节；无标题则整篇作为一个「正文」小节
- 检索：按关键词（英文词 + 中文单字/双字组合）命中打分，取命中最高的 3 个小节

## 建议的写法

每个知识点用 `##` 起一个小节，正文写清楚：**定义 / 条件 / 例子 / 常见误区**。
老师会基于这些内容设计苏格拉底式追问，所以正文越具体，追问越扎实。

## 也可以不用本地语料

配置 `.env` 里的 `IMA_API_KEY` / `IMA_CLIENT_ID` / `IMA_KB`，即可改为检索 ima 知识库（本地语料作为兜底）。
