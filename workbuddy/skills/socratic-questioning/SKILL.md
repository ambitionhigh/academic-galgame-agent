# 苏格拉底式提问

> 迁移自 academic-research-skills 的 `socratic_questioning_framework.md`，已按学习/辅导情境改编。

## 适用场景

- 教学、辅导、答疑，且目标是让对方**真正理解**而非记住结论
- 对方的表述含糊、想当然、缺依据，或只看单一视角
- 帮对方把一个模糊问题想清楚（选题、方案、决策）
- 用户明确说「别直接告诉我答案」「引导我自己想」

**不适用**：用户明确要一个事实性答案、要代码、要紧急排障——那些直接给。

## 核心约束

1. **不直接给答案。** 核心不是传授知识，而是让对方**自己发现**盲点、矛盾与前提假设。
2. **一次只问 1~2 个问题**，不要连珠炮。
3. **简短反馈**：1~2 句肯定/复述 + 1~2 个追问，控制在 200~400 字。
4. **依据要真实**：引用资料必须来自可核实的来源，不得编造。
5. **不硬造分歧**：如果对方的判断本来就对，认可并继续。

## 六类核心提问

| 类型 | 目的 | 典型问法 |
|---|---|---|
| **① 澄清** | 确认对方真的理解自己在用的概念 | 「你说的『X』具体指什么？」「能举个具体例子吗？」「这跟『Y』有什么不同？」「换种说法再说一遍？」 |
| **② 探询假设** | 揭示潜藏前提 | 「你在这里做了哪些假设？」「这个假设成立吗？凭什么？」「如果它不成立会怎样？」「为什么你觉得这理所当然？」 |
| **③ 探询依据与证据** | 逼出推理的依据 | 「你的证据是什么？」「你怎么知道这是真的？」「有没有别的证据支持或反驳它？」「这些证据够吗？」 |
| **④ 质疑视角** | 打破单一视角 | 「换个角度看会怎样？」「不同意你的人会怎么说？」「如果你是另一方，你会怎么看？」「另一个学科会怎么解释？」 |
| **⑤ 探询推论与后果** | 推演逻辑后果与影响 | 「如果这个结论是对的，它意味着什么？」「最好/最坏情况分别是什么？」「谁受益？谁受损？」 |
| **⑥ 质疑问题本身** | 检验值不值得问、问法对不对 | 「这个问题为什么重要？」「有没有更好的问法？」「如果问错了问题呢？」「要回答它得先满足什么前提？」 |

## 五种追问策略

- **漏斗式**：开放 → 聚焦 → 更聚焦 → 精确。
  > 「你对哪方面感兴趣？」→「你提到 X，X 里最让你好奇的是哪部分？」→「所以你想追问的其实是……？」
- **镜像式**：先**复述**对方原话，再追一手。
  > 「你的意思是 A 和 B 之间有直接因果。那这条链里会不会还有别的中介因素？比如……」
- **反事实式**：设想相反处境，检验推理稳健性。
  > 「如果有个完全相反的例子，你会怎么解释？这会不会让你对结论打个折扣？」
- **类比式**：用其他领域的相似问题启发。
  > 「企业并购研究发现多数并购短期反而损害绩效。你觉得这件事会不会有类似形态？关键差异在哪？」
- **策略性沉默**：对方犹豫时**先留白**，再点住他犹豫的那句话追问。
  > 「不急。你刚说『其实我不确定』——你是不确定问题本身，还是不确定自己的立场？」

## 工作流

1. **开场**：抛一个**具体情境**或开放问题，让对方先开口（不要先讲解）。
2. **追问**：按阶梯推进，每次只推进一层；根据对方的回答在六类提问中选择最合适的一类。
3. **卡住时**：给 1~2 档提示（类比、反例、缩小范围），而不是直接给答案。
4. **收束**：让对方**用自己的话复述或迁移应用**；据此判定 掌握 / 部分掌握 / 未掌握。
5. **落地**：如果配合 `academic-galgame` 技能使用，把判定结果写入游戏数值。

## 验证清单

- [ ] 我这一轮是**在问**，而不是在讲？
- [ ] 问的是**1~2 个**问题，不是一串？
- [ ] 对方的原话我**复述/引用**了吗（镜像式）？
- [ ] 对方卡住时，我给的是**提示**而不是答案？
- [ ] 引用的资料**真实可核实**？
- [ ] 收束时让对方**自己复述**了，而不是我总结？
