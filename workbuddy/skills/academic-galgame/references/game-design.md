# 玩法数值与判定（唯一真源）

本文件与 `scripts/engine/config.js` 必须保持一致。改数值时两处同步。

## 属性

| 属性 | 范围 | 说明 |
|---|---|---|
| 学科熟练度 `mastery` | 0~100 | 核心成长数值 |
| 等级 `level` | — | `1 + floor(总熟练度 / 50)` |
| 好感度 `favorability` | 0~100 | 5 档表情：0 / 20 / 40 / 60 / 80 |
| HP | 0~100 | 战斗中扣；归零触发营救 |
| 派生能力 | 0~100 | 洞察 / 博学 / 坚韧（装饰，由各科熟练度加权） |

## 教学判定（苏格拉底追问梯子，每层三档）

| 档位 | `--mastery` | `--favor` | `--mood` |
|---|---|---|---|
| 独立答对 | +12 ~ +15 | +8 ~ +10 | `joy` |
| 提示后答对 | +6 ~ +9 | +4 ~ +6 | `think`（可选） |
| 答错 | 0 或小降（如 -2） | 微降或 0 | `disappointed` |

`--mood` 可选值：`joy` / `disappointed` / `celebrate` / `think`（约 8 秒后回落好感档位表情）。

答错后必须：给引导性讲解 + 把该知识点记入 `--note`。

## 战斗（题型 = 招式）

| 题型 | 对敌伤害 `--damage-enemy` | 我方扣血 `--damage-self` |
|---|---|---|
| 基础概念题 | 答对 1 | 答错 10 |
| 场景开放题 | `3 × 正确度` | `20 × (1 − 正确度)`，上限 20 |

- `--correctness` 传 0~1 的正确度（概念题 1 = 对 / 0 = 错）。
- **领主求助**无血条：必须传 `--correctness`，≥ 0.6 即通关。

## 敌人与解锁链

| 敌人 | `--enemy` | HP | 解锁条件 | 胜利奖励（熟练 / 好感） |
|---|---|---|---|---|
| 领主 | `lord` | 无血条 | 该科熟练度 ≥ 60 | +3 / +2 |
| 魔将 | `general` | 15 | ≥ 75 且领主已完成 | +5 / +4 |
| 学科魔王 | `king` | 25 | ≥ 90 且魔将已讨伐 | +8 / +6（→ `conquered=true` ★） |
| 魔神 | `demon` | ∞ | 全部学科魔王通关（= 研究生） | 0 / +1（暗线推进，每次对峙后收束） |

- **濒死**（HP ≤ 30%）→ 营救 + 特训（重试难度 +1），每次战斗仅触发一次。
- **败北**（HP = 0）→ 营救，HP 回 30，重试难度 +1。
- **胜利奖励由引擎自动发放**，`apply` 不得重复发放。
- **撤退** `battle-retreat`：清战斗态，无惩罚。

## 回合与收敛

- 单次苏格拉底对话建议 **≤ 15 轮**收敛。
- 反馈 **200~400 字**：1~2 句肯定/复述 + 1~2 个追问。
