【怎么开始】

  双击文件夹里的「学术galgame.exe」。

  浏览器会自动打开。完事。

  第一次打开时，页面会停在「⚙ 设置」那一页 —— 这是故意的，
  因为还没填大模型 Key。填完保存，鲸鱼娘就变成真的 AI 老师了。

  想方便点：第一次运行会自动在桌面建一个快捷方式
  （名字就叫「学术galgame」，图标是鲸鱼娘），以后双击桌面图标就行。


【第一次要填什么】

  打开页面后点右上角「⚙ 设置」，有两块要填：

  ① 大模型（必须填一个，否则是 DEMO 模式）
     填三样：API Key、模型名、接口地址。
     比如用 DeepSeek：
        接口地址  https://api.deepseek.com
        模型名    deepseek-chat
        API Key   你自己的 Key

  ② ima 知识库（可选，但强烈建议填）
     这样鲸鱼娘出题时会去你的知识库里找真实资料，而不是凭空讲。

  填完点「保存到本机浏览器」。
  这些 Key 只存在你自己的浏览器里，不会上传到任何地方。


【怎么确认它「真的变智能了」】

  看网页右上角：

    橙色「DEMO 模式」   →  还是假的，没填 Key
    白色「你的模型名」  →  真的 AI 老师，成功了

  小测试：对它说「我不想学博弈论」。
  真 AI 会换话题或反问你；DEMO 模式只会照旧抛那几个固定问题。


【怎么关掉】

  游戏是跑在后台的（关掉浏览器它还在跑）。

  想彻底关掉：双击「停止.bat」。

  下次再玩：双击桌面图标 或 「学术galgame.exe」 就行。


【出问题了怎么办】

  双击「自检.bat」——它会检查所有文件是否完整，把结果打在窗口里。
  把它显示的内容发出来，就能定位问题。

  双击「排查模式.bat」——会在窗口里显示运行日志，
  出问题时用这个启动，把窗口里的内容复制出来即可。

  常见情况：

    双击没反应
      → 看「自检.bat」的结果。
      → 确认整个文件夹是一起解压出来的，
        不要只把 exe 单独拖到别处。

    浏览器没自动打开
      → 正常，手动打开浏览器，地址栏输入 http://127.0.0.1:8787

    提示端口被占用
      → 说明已经开着一个了。双击「停止.bat」，再重新打开。

    Windows 提示「已保护你的电脑」
      → 点「更多信息」→「仍要运行」。
        这是没有花钱买数字签名的软件都会遇到的提示，不是病毒。


【它会不会把我的 Key 传出去】

  不会。程序完全跑在你自己的电脑上：

    · 服务只监听 127.0.0.1，只有本机能访问
    · 网页里填的 Key 存在你浏览器的本地存储里
    · 如果你在 exe 旁边放了 .env 文件，那个文件也只在你本机

  唯一的对外连接是你自己填的那个大模型接口和 ima 接口。


【想卸载】

  直接删掉整个文件夹就行，不留任何残留。

  再顺手删掉这两个地方（如果存在）：
    · 桌面的「学术galgame」快捷方式
    · C:\Users\你的用户名\AppData\Local\学术galgame\（日志目录）
