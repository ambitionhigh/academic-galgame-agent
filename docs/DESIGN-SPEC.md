# 学术galgame Agent · 设计规格

> 版本 **v2.0**（独立开源版）· 载体：零依赖 Node.js Agent + 原生 Web UI
> 前身：DeepSeek Harness 上的「学术galgame」插件（v1.2）。本版把它抽成**可独立运行、可开源、Trae 就绪**的 Agent 项目。

---

## 1. 一句话概述

一个「读书练级、答题打怪」的学习优先 RPG：老师（LLM）与伙伴（鲸鱼娘）一体，教材语料当依据，通过**苏格拉底式情境教学**提升学科熟练度；逐科讨伐各自魔王，最终面对**不可战胜的全知魔神**。

## 2. 核心定位

- **学习优先，游戏是外衣**：题目要真难、答错有代价、掌握可量化。
- **不是聊天机器人**：有完整的「提问 → 判定 → 数值 → 解锁 → BOSS 战 → 结算」闭环。
- **非目标**：多人在线、复杂地图寻路、实时战斗动画、语音。

## 3. 与 v1.2（DSH 插件版）的差异

| 维度 | v1.2（DSH 插件） | v2.0（本开源版） |
|---|---|---|
| 运行载体 | 挂在 DSH 组合插件 + 预设内 | 独立 Node 服务 + Web UI，`git clone` 即跑 |
| 界面 | DSH Client 面板（slot overlay） | 原生 HTML/CSS/JS galgame 界面 |
| 模型后端 | DSH 会话自带模型 | **任何 OpenAI 兼容接口**（`POST {baseUrl}/chat/completions` + Bearer）；不绑定供应商，Base URL 留空默认火山方舟 |
| 工具形态 | DSH `defineTool` + `ctx.tools.register` | OpenAI function-calling + GM 编排循环 |
| 检索 | 内置 ima 凭证 | 本地语料 `corpus/`（默认）+ 可选 ima |
| 依赖 | DSH 运行时 | **零第三方依赖**（Node ≥ 18 内置模块） |
| 协作 | — | Trae 项目规则 / 技能 / AGENTS.md |

## 4. 教学与掌握（苏格拉底 → 连续正确度）

### 4.1 最小单元：知识点
```
{ 目标概念（一句话命题）, 追问梯子（2~4 层由浅入深）,
  判定要点（需命中的关键逻辑）, 熟练度（0~100）, 学科 }
```

### 4.2 一次苏格拉底对话

1. **引出**：老师用情境抛开放性问题。
2. **追问梯子**：逐层追问，每层三档——独立答对（大步↑）/ 提示后答对（中步↑，给 1~2 档提示）/ 答错（降难度引导，记入近期重点）。
3. **收束**：老师总结，学生复述/应用 → 判定 掌握 / 部分掌握 / 未掌握。
4. **调度**：未掌握 → 明天；部分 → 3 天；掌握 → 7→14→30 天递进（v2.0 暂以「近期重点」日志承载，完整间隔重复为后续迭代）。

提问方法完整定义见 `.trae/skills/socratic-questioning/SKILL.md`（六类提问 / 五种策略 / 硬约束）。

### 4.3 连续正确度

- **场景开放题**按 rubric 打「正确度 0~100%」（依据：命中要点数量、逻辑完整度、能否迁移应用）。
- **基础概念题**二值判定。
- 正确度统一喂两处：`熟练度增减` + `战斗攻防`。

## 5. 战斗系统（题型 = 招式）

| 题型 | 对敌伤害 | 我方扣血 |
|---|---|---|
| 基础概念题 | 答对 1 | 答错 10% |
| 场景开放题 | 3 × 正确度 | 20% × (1 − 正确度)，上限 20% |

- 我方 HP = 100；魔将 ≈ 15；学科魔王 ≈ 25；魔神 = ∞（不可战胜）。
- **判定**：模型当 GM 判卷，算好伤害调用 `ag_battle_apply`；引擎只做血条 clamp、胜负结算、存档，不自动判题。
- **胜利奖励由引擎在结算时自动发放**——领主 +3 / 魔将 +5 / 魔王 +8 熟练度；好感 +2 / +4 / +6；魔王讨伐 → `conquered=true`（★）。败北 → 心情 disappointed。GM 不得重复发放。
- **战斗态**：仅存内存，不写存档；永久进度（任务链、conquered、熟练度、好感）写存档。
- **撤退**：`ag_battle_retreat`，清战斗态，无惩罚。

## 6. 成长曲线

- **等级** = 总熟练度的可视化数字（`1 + floor(总熟练度/50)`）。
- **研究生** = 全部学科**学科魔王**通关（防偏科），是重要里程碑但**不是终点**。
- **魔神** = 精通所有科目的全知化身，**无限血条、无法被打败**，是永恒的追求目标。

## 7. 世界观与角色

- **核心设定**：「知识即魔力」，读书/掌握知识变强；无知滋生魔物。
- **基调**：轻松魔法学院风 + 一条严肃暗线。

| 角色 | 设定 |
|---|---|
| 你 | 学徒，深读各科 → 研究生 → 挑战全知魔神 |
| 鲸鱼娘 | 伴读魔导书精灵（鲸鱼形态），老师 + 伙伴；与魔神有渊源（暗线） |
| 学科领主 | 各学科地区权威学者，发场景任务 |
| 学科魔将 | 该学科「错误认知」的化身，讨伐 = 期中 |
| 学科魔王 | 该学科「无知」的化身，讨伐 = 期末决战 |
| 魔神 | 全知化身，无限血条，不可战胜 |

## 8. 特殊剧情（每次进步实时生成）

无固定结局，叙事由「进步」驱动：学科首达 60 → 领主登场；讨伐魔将 → 地区战报；讨伐魔王 → 征服纪念 + 暗线推进；等级里程碑 → 成长回顾；好感档位变化 → 专属互动；达成研究生 → 解锁魔神；每次挑战魔神 → 对峙剧情。

## 9. 美术

- **立绘**：`src/web/assets/whale-girl/*.png`，**水平精灵图**，每帧 256×256，帧数 = 宽 / 256。
- **动画**：前端用 JS 逐帧切换 `background-position-x`（220ms/帧），不同状态帧数不同（见 `src/engine/config.js` 的 `STATE_FRAMES`）。
- **5 档好感度**表情：陌生 → 友好 → 亲近 → 信赖 → 亲密。
- **敌人**：v2.0 用纯文字敌人卡（暗色卡 + 大血条）；敌人像素立绘留待后续。

## 10. 存档

- 位置：`./data/save.json`（可用 `GALGAME_SAVE` 覆盖），已 gitignore。
- 内容：等级、各学科熟练度、好感度、任务链 `quest.lord/general/king`、`conquered`、奖励/称号、日志。
- **向后兼容**：读取旧存档时对缺失字段自动补默认值。
- 战斗态不写存档（会话内内存态）。

## 11. 架构

三层单向依赖（详见 README「架构」一节）：

- **engine/**：纯游戏逻辑（配置常量 / 状态机 / 战斗 / 存档 / 会话）。**不发网络请求**。
- **agent/**：人设、大模型接口客户端（任何 OpenAI 兼容服务）、检索适配、GM 编排（工具定义 + 调用循环 + demo 兜底）。
- **server/**：零依赖 HTTP 服务，伺服静态 UI 与 `/api/*`。
- **web/**：原生 UI，只通过 `/api/*` 通信。

## 12. 硬依赖与前提

1. **大模型接口**：`LLM_API_KEY` + `LLM_MODEL`（未配置则 DEMO 模式）。接口为 OpenAI 兼容的 `POST {LLM_BASE_URL}/chat/completions` + Bearer 鉴权，**不绑定供应商**；`LLM_BASE_URL` 留空时默认火山方舟。已实测 DeepSeek 与火山方舟，其它兼容服务理论可用。
2. **教材来源**：`corpus/` 本地语料（默认）；可选 ima 知识库。
3. Node.js ≥ 18。

## 13. 非目标 / 明确不做

不做娱乐优先的轻松模式、多用户/联机、复杂实时战斗动画、地图寻路；v2.0 不做语音、不做 AI 实时生成立绘。

## 14. 待定 / 后续可细化

- 完整的间隔重复调度（SM-2 类算法）与知识点卡持久化。
- 派生能力（洞察/博学/坚韧）的具体 buff 规则。
- 敌人像素立绘。
- 语料 → 知识点树 → 学科自动归纳。
- 多供应商特化适配（通用 `llm.js` 之上再加 provider 抽象，处理各家鉴权/参数的细微差异）。
