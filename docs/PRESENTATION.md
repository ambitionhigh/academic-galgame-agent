# 展示脉络 · 学术galgame

> 这份文档只解决一件事：**怎么把它讲得让人跟着走**。
>
> 不是功能清单 —— 清单讲完人就忘了。这里给的是**一条有递进的线**：
> 每一段都回答上一段留下的疑问，最后落到一个别人拿不走的证据上。

---

## 0. 先记住这一句

> **「它不是在陪你聊天，它在教你自己想明白；而且这一点不是我说了算，是实测出来的。」**

整场展示的每一段，都在给这句话添一块砖。忘了词就回到这句话。

---

## 1. 主线：六段递进

每段的结构都是 **【做一个动作】→【说一句话】→【它留下了什么疑问】**，
下一段正好接住那个疑问。**不要跳段** —— 跳了就变成念功能。

### 第 ① 段 · 反常识开场：它拒绝回答你

| | |
|---|---|
| **做什么** | 打开游戏，输入「**我想学纳什均衡**」 |
| **你会看到** | 老师**不讲定义**，而是抛一个情境：「深海里两片渔场，各有一位渔夫。鱼汛季每人只能选一次：限量捕捞，还是疯狂捕捞？——为什么『两家都限量』看起来最好，最后却常常双双跑去疯狂捕捞？」 |
| **说什么** | 「注意它**没有**回答我的问题。它反问了我一个更具体的问题。」 |
| **留下的疑问** | 一个 AI 凭什么敢不回答？它不怕露怯吗？ |

> 💡 这一段的价值全在"反常识"。**千万不要先解释**，让观众自己愣一下。

### 第 ② 段 · 解释：因为「怎么提问」是被工程化管起来的

| | |
|---|---|
| **做什么** | 切到编辑器，打开 `.trae/skills/socratic-questioning/SKILL.md`（或直接念目录） |
| **你会看到** | 六类提问（澄清 / 探询假设 / 探询依据 / 质疑视角 / 探询推论 / 质疑问题本身）、五种追问策略（漏斗 / 镜像 / 反事实 / 类比 / 策略性沉默）、三档追问梯子 |
| **说什么** | 「它敢不回答，是因为**提问方法本身是一份被管理的工程资产**。项目规则里写死了：任何涉及教学方式的改动，必须先把这份技能加载进来。所以它不是靠模型临场发挥。」 |
| **留下的疑问** | 会提问很好——可它怎么知道我**该学什么**？ |

### 第 ③ 段 · 转折：课程表是你自己的

| | |
|---|---|
| **做什么** | 点右上 **⚙ 设置** → 滚到 **② ima 知识库** → 点 **「拉取知识库列表」** → 对着某个知识库点 **「+ 添加为学科」** |
| **你会看到** | 右侧「学科熟练度」里**当场多出一条新学科** |
| **说什么** | 「点一下，这个知识库就变成了一门学科。**你 ima 里有什么，游戏里就能学什么。**」 |
| **留下的疑问** | 那它真的读得到我库里的东西吗？ |

> ⚠️ 这里只演示"变成学科"，**先不要**演示能读到内容 —— 那是第 ④ 段的高潮，别提前放。

### 第 ④ 段 · 高潮：接上知识库 ≠ 读得到书（实测）

这是整场最有分量的一段，因为它是**别人没做、而你做了并且验证了**的地方。

| | |
|---|---|
| **做什么** | ① 点 **「把书下载并解析到本地」**，展示返回：`共 10 个文件，已解析 6 本（131.7 万字）；4 个读不了（扫描版/图片版/网页笔记）`<br>② 然后在对话里粘贴这句（**学科要写明**，见下方注意）：<br>「**请在「健康」学科下用 ag_retrieve 检索「睡眠不足对免疫系统的影响」，然后引用你查到的原文讲一段**」 |
| **你会看到** | 老师先亮出**原文引用**，再开始提问。实测原话：<br><br>📖 **原文引用**（来自你的知识库〔马修·沃克《我们为什么要睡觉》〕）：<br>「本章描述了睡眠不足对人体所有主要的生理系统（**包括心血管、代谢、免疫和生殖**）产生损害的各种方式……睡眠越短，生命越短。」<br><br>接着它自己转到教学：<br>「那么，第一个问题来了——**不给你答案**，你自己想：……先说说你的直觉，再告诉我你**为什么**这么猜。」 |
| **说什么** | 「接上知识库就完了吗？**不是。** 我们实测发现 ima 的两个硬限制：<br>**① 它的搜索只匹配书名、不搜正文** —— 查『投资』能命中 23 条，查『复利』『注意力』一律 0 条，哪怕书里到处都是；<br>**② 它给的是 PDF/EPUB 原始文件** —— 当文本读只会得到 `%PDF-1.6 %äüöß...` 这种乱码。<br>所以我们自己做了一整套：**列文件 → 下载 → 抽正文 → 存本机 → 本地全文检索**。纯标准库，连 PDF 中文字体的 CMap 都是自己解析的。」 |
| **留下的疑问** | 这套东西只在一个版本里能用吧？ |

> 💡 如果时间只够留一段，**留这段**。
> 📌 那句「4 个读不了（扫描版/图片版/网页笔记）」**一定要让观众看到** ——
> 它证明的是诚实：读不了就说读不了，而不是假装读过。
>
> ⚠️ **为什么要在提示里写明「健康」学科**：检索时按学科去对应的知识库找。
> 不写的话模型得自己猜学科（实测它多半猜得对，但现场别赌）。写明最稳。
>
> ⚠️ **回答要等 3~8 秒**。这几秒**不要说话** —— 让结果自己出现，比任何解释都有力。

### 第 ⑤ 段 · 加码：三个版本，而且可复验

| | |
|---|---|
| **做什么** | 终端里跑一条命令：`node scripts/check-textract.js <样本目录>` |
| **你会看到** | ```
✓ book0_epub.epub  epub  257859 字  708e0897bcb4
✓ book1_pdf.pdf    pdf   250407 字  084352b027b6
✓ book3_epub.epub  epub  205595 字  4dbb6dec3044
结果：4/4 一致
``` |
| **说什么** | 「同一本书，**Node 版和 Python 版抽出来的正文逐字节相同** —— 连哈希都一样。这不是巧合，是有一条回归测试守着：不一致就退出码 1。<br>因为最难受的 bug 就是『桌面版能读、另一个版本读不了』。」 |
| **留下的疑问** | 那到底有几个版本？为什么要做三个？ |

### 第 ⑥ 段 · 收尾：泛用性不是口号

| | |
|---|---|
| **做什么** | 展示三行启动命令（不用真跑，念出来就够） |
| **你会看到** | ```
node src/server/server.js     # Trae 版：完整项目，零依赖
python run.py                 # Python 版：同架构换语言
双击 学术galgame.exe          # 桌面版：10.9 MB，对方电脑什么都不用装
``` |
| **说什么** | 「有人会问：这套东西是不是绑死在 Node 上？<br>所以我们用**纯标准库**又实现了一遍：同样的引擎、同样的数值、同一份自测，**前端一行没改**（哈希一致）。<br>换语言要改的只有语法 —— 架构、边界、接口一律保持。<br>**泛用性不是一句口号，是一份可以跑的验收标准。**」 |

## 2. 按时间砍：三种讲法

六段是有优先级的。时间不够就**从后往前砍**，但 ① 和 ④ 永远保留。

| 时长 | 讲哪几段 | 怎么砍 |
|---|---|---|
| **60 秒**（走廊/电梯） | ① → ④ | 只做两个动作：抛情境、然后引用原文。中间一句过渡：「它凭什么敢不回答？这个待会儿说 —— 先看它能不能读到我的书。」 |
| **3 分钟**（标准） | ① → ② → ④ → ⑥ | 砍掉 ③（知识库变学科）和 ⑤（哈希一致）。③ 的一句话并进 ④ 的开头。 |
| **10 分钟**（推荐） | 全六段 | 原样走。每段 1~2 分钟，④ 给足 3 分钟。 |
| **30 分钟**（深度） | 全六段 + 现场问答 | 在 ⑤ 之后插入**现场跑测试**：`node scripts/smoke.js`、`python -m unittest discover -s tests`、`node scripts/check-panel-replay.js` —— 让观众看着全绿。 |

## 3. 按听众调：重点不一样

同一套六段，**换一下 ② 和 ⑥ 的说法**就行。

| 听众 | ② 强调什么 | ⑥ 强调什么 | 少讲 |
|---|---|---|---|
| **技术评审 / 招聘方** | 「提问框架是可加载的技能，项目规则强制引用」→ 工程约束 | 「三版本逐字节一致 + 回归测试守着」→ 可复验 | 游戏的数值系统 |
| **老师 / 教育从业者** | 「六类提问、五种策略」→ 这是教学法，不是 prompt | 「每个人学自己的资料」 | 哈希、零依赖 |
| **同学 / 普通用户** | 「它会一直问你，直到你自己想明白」 | 「下载解压双击，什么都不用装」 | 架构、版本对比 |
| **开源社区** | 「零依赖、MIT、Trae 原生就绪」 | 「欢迎来跑那条一致性测试」 | 商业价值 |

## 4. 现场操作卡（照着点，别临场找）

> 提前把这些准备好，现场只做动作不找路。

**开场前 3 分钟**

```bash
# 1) 启动（三选一，用桌面版最省事）
双击桌面的「学术galgame」图标          # 会自动开浏览器

# 2) 确认它已经连上真模型：看右上角
#    橙色「DEMO 模式」 = 还没配 → 现场配要花时间，别赌
#    白色「deepseek-chat」 = 已就绪 ✓

# 3) 确认知识库已经索引过（第 ④ 段才不用等）
#    ⚙ 设置 → ② → 点一次「把书下载并解析到本地」
#    看到「已解析 N 本」就够了，现场不用再点

# 4) 把终端切到仓库目录，光标停在命令行
```

**第 ④ 段的确切点击顺序**

1. 右上 **⚙ 设置**
2. 滚到 **② ima 知识库**
3. 点 **「把书下载并解析到本地」**（如果已经索引过，它会秒回并显示「已解析 N 本」—— **这也很好**，顺口说一句「第二次是秒回，书不会重复下载」）
4. 关掉设置，在底部输入框粘贴：
   > 请在「健康」学科下用 ag_retrieve 检索「睡眠不足对免疫系统的影响」，然后引用你查到的原文讲一段
5. 等 3~8 秒 —— **不要在这几秒里说话**，让结果自己出现
   （实测 3~4 秒；首次冷启动可能到 8 秒）

**第 ⑤ 段的确切命令**

```bash
cd "D:\deepseek harness\academic-galgame-agent"
node scripts/check-textract.js "D:\deepseek harness\.tmp\books"
```

## 5. 四个「必炸」时刻

这四个是现场最能出效果的，**每个都只花几秒**：

| # | 时刻 | 观众的反应 |
|---|---|---|
| 1 | **老师拒绝回答**，反而反问你一个更具体的问题 | 「诶？它不回答？」 |
| 2 | **点一下知识库，右侧当场多出一门学科** | 「哦——课程表是我自己的」 |
| 3 | **它逐字引用你书里的原文**，还自己声明「我不替你加料」 | 「这确实是读到了」 |
| 4 | **跑一致性测试，两版哈希一模一样** | 「这个是真的验过」 |

> 第 3 个是主菜，前两个是铺垫，第 4 个是收尾。
> **顺序不能换** —— 第 4 个如果放在前面，就成了炫技。

## 7. 翻车预案

| 如果…… | 怎么办 |
|---|---|
| **网络断了 / 模型超时** | 别慌，**这本身就是个演示点**：「它没配模型时会进 DEMO 模式，界面和数值系统照常可用」—— 然后把 ⑤ 段的一致性测试跑了，那段完全离线 |
| **知识库第一次索引很慢** | 提前索引好。万一现场卡住，就说：「第一次要把书下下来抽正文，实测 10 个文件 34 秒 —— 我提前跑过了，这里直接看缓存的结果」 |
| **它引用的内容不对** | **别圆场**。说：「这说明检索没命中，我们看一下知识库状态」→ 打开 ⚙ 设置点一次索引，看「读不了」的清单。**诚实比流畅加分** |
| **有人问「这不就是套壳吗」** | 直接接第 ② 段：「如果只做一个 prompt，它确实就是套壳。区别在于提问方法是**可加载、可校验、项目规则强制引用**的技能文件 —— 这是工程约束，不是提示词。」 |
| **有人问「为什么不做成 X」** | 「三个版本已经证明架构不绑语言；你说的 X 大概率是换个壳，接口契约不用动。」 |

## 8. 不要做的事

- ❌ **不要开场念功能清单**。第一句必须是**做一个动作**，不是介绍。
- ❌ **不要提前剧透第 ④ 段**。第 ③ 段只演示"变成学科"，绝不说"它能读到内容"。
- ❌ **不要解释技术细节超过 20 秒**。技术评审会自己问；普通听众会走神。
- ❌ **不要说"AI 会思考"之类的话**。说它做了什么、验证了什么。
- ❌ **不要跳过"4 个读不了"那条**。那是全场最能建立信任的细节。
- ❌ **不要在 ④ 段结果出来时说话**。让画面自己说。
