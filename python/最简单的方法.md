# 最简单的方法（只看这一页就够）

> 其它文档你可以完全不看。这里只有两种方法，选一种，30 秒搞定。

---

## ⚠️ 先回答一个常见疑问：「为什么它一点都不智能？」

因为你还没接上 AI。

程序**内置了一个 DEMO 模式**：没配大模型时，老师只会重复几句写死的话，
**你输入什么都不会变**。那不是 AI 在回答，是几行固定文本。

**接上之后**，它才会真的读你的回答、真的追问。第一次启动时会自动问你一次，
照着填就行（见下面方法一的第 3 步）。

---

## 方法一：双击（推荐，一个字都不用打）

1. 打开文件夹：

```
D:\deepseek harness\academic-galgame-agent\python
```

2. **双击 `启动.bat`**

3. **第一次会弹出一个配置向导**，问你两件事：

   - 「请选择你要用的大模型服务」→ 直接按回车（默认选 1 = DeepSeek）
   - 「请粘贴你的 API Key」→ **粘贴你的 Key，回车**

   它会当场测试连接，成功后提示 `[OK] 连接成功！`

   > 没有 Key？在向导里输入 `0` 跳过，先用 DEMO 模式玩。
   > 想申请的话看 `新手部署教程.md` 第 5 步。

4. 配置完成后，浏览器会**自动打开**。完事。

**以后每次只要双击 `启动.bat` 就行**，不会再问你（配置记住了）。

> 那个黑窗口就是程序本身，**别关它**。玩完了想关掉，关掉窗口就行。

**想改配置？** 双击 **`首次配置.bat`** 重新问一遍。

---

## 方法二：复制粘贴一行（双击没反应时用）

1. 按键盘 **Win 键 + R**，输入 `powershell`，回车（会出现一个蓝底或黑底的窗口）；

2. **复制下面一整行**，在窗口里**右键粘贴**，然后按**回车**：

```powershell
cd "D:\deepseek harness\academic-galgame-agent\python"; $env:GALGAME_OPEN="1"; python run.py
```

3. 浏览器会自动打开。

> 如果你的文件夹装在别的地方，把引号里那段换成你自己的路径就行，其余照抄。
>
> 这条路**不会**弹配置向导。要配 Key 的话，双击一次 `首次配置.bat` 即可。

---

## 玩完了怎么关

关掉那个窗口，或者在窗口里按 **Ctrl + C**。

下次想再玩：**再双击一次 `启动.bat`** 就行，不用重新装任何东西。

---

## 怎么确认「它真的变智能了」

看网页**右上角**：

| 你看到的 | 说明 |
|---|---|
| 橙色的 `DEMO 模式 · 点「⚙ 设置」填自己的 Key` | ❌ 还是假的，没配上 |
| 白色的 `deepseek-chat`（或你的模型名） | ✅ 真的 AI 老师，成了 |

**一个快速验证**：在输入框里随便说句「我不想学博弈论」——
真 AI 会换个话题或反问你；DEMO 模式会照旧抛那几个固定问题。

## 配置存在哪？安全吗？

存在 `python\.env` 这个文件里，**只在你本机**，也**不会**被上传到 GitHub
（已在 `.gitignore` 里排除）。

> 如果你以后要把这个服务放到公网上给别人用，请把 `.env` 里的 Key 清空 ——
> 否则任何人都能用你的额度。让访客各自在网页「⚙ 设置」里填他们自己的 Key。

---

## 万一不行（只有这 4 种情况）

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击后黑窗口**一闪就没了** | 没装 Python，或装的时候没勾 "Add Python to PATH" | 看 `新手部署教程.md` 的**第 1 步**，几分钟 |
| 向导里提示 **`[X] 没连上`** | Key 不对 / 模型名不对 / 网络问题 | 它会告诉你具体原因和原始报错；重开一次向导再试 |
| 提示**端口 8787 已经被占用** | 你已经开着一个了 | 找到那个黑窗口按 Ctrl + C 关掉；或者重启电脑 |
| 浏览器**没自动打开** | 正常，有时会这样 | 手动打开浏览器，地址栏输入 `http://127.0.0.1:8787` |

**还不行**？把黑窗口里的内容（右键 → 全选 → 复制）发我，我看一眼就知道。
