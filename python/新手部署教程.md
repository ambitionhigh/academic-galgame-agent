# 新手部署教程（零基础版）

> 这份教程假设你**从来没有用过命令行**。每一步都写清楚「在哪里、输入什么、会看到什么」。
> 照着做，大约 15 分钟能跑起来。
>
> 本教程的所有步骤都在 **Windows + 中文系统**上实测过，不是照抄文档。

---

## 先看：你最后会得到什么

一个网页版的 AI 教学游戏。打开浏览器就能看到：

- 一位叫「鲸鱼娘」的 AI 老师，用**提问**的方式带你学知识点（它不会直接给答案）；
- 右侧是学习面板：各科熟练度、好感度、任务链进度；
- 学习进度会自动记录。

**不填任何密钥也能玩**（叫 DEMO 模式）。想让它真的会思考、真的听你说话，再往下看第 5 步。

---

| 需要 | 说明 |

## 第 1 步：装 Python

### 1.1 先看看是不是已经装了

1. 按键盘上的 **Win 键 + R**（Win 键就是键盘左下角那个小窗户图标）；
2. 会弹出一个小窗口，在里面输入 `cmd`，然后按回车；
3. 出现一个**黑色的窗口**（这就是「命令提示符」，后面简称「命令行」）；
4. 在黑窗口里输入下面这行，按回车：

```
python --version
```

**会看到两种情况：**

- ✅ **好**：显示类似 `Python 3.14.1` —— 说明已经装好了，**直接跳到第 2 步**。
- ❌ **不好**：显示 `'python' 不是内部或外部命令，也不是可运行的程序` —— 说明没装，继续往下看。

### 1.2 安装 Python

1. 打开浏览器，访问 **https://www.python.org/downloads/**
2. 点页面上的黄色大按钮 **Download Python 3.x.x**（下载安装包）；
3. 双击下载好的安装包，**关键一步来了**：

> ⚠️ **安装界面的第一屏，最下面有一个复选框，写着
> `Add python.exe to PATH`（或 `Add Python to PATH`）。
> 一定要把它勾上！**
>
> 这是新手最容易踩的坑。不勾的话，装完了命令行还是找不到 python，
> 你会看到「不是内部或外部命令」，然后卡在这一步。

4. 勾上之后，点 **Install Now**，等它装完，点 Close。

### 1.3 验证一下

**把刚才那个黑窗口关掉，重新开一个**（重要：必须是新开的窗口，旧窗口不会刷新）。

再输入一次：

```
python --version
```

这次应该显示 `Python 3.14.1` 之类的版本号。

> 如果还是提示「不是内部或外部命令」：说明第 3 点那个勾没勾上。
> 重新运行安装包，选 **Modify**，把 `Add to PATH` 补上；或者干脆卸载重装一次，这次记得勾。

## 第 2 步：把代码下载到电脑

### 方式 A：下载压缩包（推荐，不用装别的东西）

1. 浏览器打开：**https://github.com/ambitionhigh/academic-galgame-agent**
2. 找到绿色的 **Code** 按钮，点开 → 点 **Download ZIP**
3. 下载完成后，**解压**到一个好找的位置。建议解压到：

```
D:\academic-galgame-agent
```

> 💡 **关于路径**：路径里可以有中文，但**建议用简单短路径**（比如 `D:\academic-galgame-agent`），
> 别放在桌面或特别深的目录里，能少很多麻烦。

### 方式 B：用 Git 克隆（已经装过 Git 的选这个）

在命令行里输入（把 `D:\` 换成你想放的位置）：

```
cd /d D:\
git clone https://github.com/ambitionhigh/academic-galgame-agent.git
```

## 第 3 步：启动它

### 最简单的方式：双击

进入你解压/克隆出来的文件夹，再进入里面的 **`python`** 文件夹，找到一个叫 **`启动.bat`** 的文件，**双击它**。

会弹出一个黑色的窗口，显示：

```
  ==========================================
    学术galgame Agent  Python 版
  ==========================================

  正在启动，请稍候...

  启动成功后，用浏览器打开：http://127.0.0.1:8787
  想停止：在这个窗口按 Ctrl + C，或者直接关掉本窗口。
```

**看到这些就说明成功了。**

> ⚠️ **这个黑窗口不要关掉**。它就是服务本身，关掉服务就停了。
> 你可以把它最小化，然后去做第 4 步。

### 或者用命令行启动

```
cd /d D:\academic-galgame-agent\python
python run.py
```

如果路径不同，把 `D:\academic-galgame-agent` 换成你自己的。

启动成功的话，会看到：

```
  [OK] 学术galgame Agent（Python 版）已启动

    请在浏览器打开：  http://127.0.0.1:8787
    模型来源：BYOK 模式（服务端未放任何 Key，由每位访客自带凭证）

    停止服务：在本窗口按 Ctrl + C
```

## 第 4 步：打开浏览器

打开 Chrome / Edge / 任何浏览器，在地址栏输入：

```
http://127.0.0.1:8787
```

按回车。**你应该看到**：

- 左上角写着「学术galgame」，下面一行小字「鲸鱼娘老师 · 苏格拉底式教学」；
- 左边是一位蓝色头发的鲸鱼娘立绘；

到这里你就**已经能玩了**。在输入框里打点字，按发送试试。

> 但你会发现：不管你说什么，老师的回复都是那几句固定的。
> 因为 DEMO 模式里没有真正的 AI。想要真老师，继续第 5 步。

## 第 5 步（可选）：接上真的 AI 老师

### 5.1 先理解两件事

1. **需要一个「模型密钥」**。它相当于 AI 的使用凭证，按用量收费，学习用途通常**几分钱到几块钱**级别。
2. **密钥只存在你自己的浏览器里**，不会上传到任何服务器。这个软件的服务端不保存你的密钥。

本教程用 **DeepSeek**（国内、便宜、注册简单）举例。用火山方舟、OpenAI 等其它服务也一样，填法在 5.4 说明。

### 5.2 拿到 DeepSeek 密钥

1. 浏览器打开 **https://platform.deepseek.com**
2. 注册 / 登录账号；
3. 在左侧找到 **API Keys**（或「API 密钥」）页面；
4. 点 **创建 API Key**，起个名字；
5. **复制弹出的那串密钥**（形如 `sk-xxxxxxxx...`）。

> ⚠️ **这串密钥通常只完整显示一次**，关掉弹窗就可能再也看不到了。
> 请立刻粘贴到记事本存好。
>
> 如果页面提示需要先充值：充最小额度即可，够用很久。
>
> （具体界面以官网实际为准，各家平台大同小异。）

### 5.3 填进软件里

1. 回到浏览器里的那个页面（`http://127.0.0.1:8787`）；
2. 点右上角的 **⚙ 设置**；
3. 找到 **① 大模型接口（老师 · 任何 OpenAI 兼容服务）**，填三个格子：

| 格子 | 填什么 |
|---|---|
| **API Key** | 粘贴你刚复制的那串 `sk-...` |
| **模型 ID** | `deepseek-chat` |
| **Base URL（可留空）** | `https://api.deepseek.com` |

4. 点下面的 **测试模型连接** 按钮。

**等 5~30 秒**，会看到结果：

- ✅ **`[OK] 连接成功，模型返回：收到`** —— 成了！
- ❌ 红色错误 —— 跳到下面「常见问题」对照排查。

5. 最后点 **保存**（面板底部的保存按钮）。

### 5.4 用别的服务怎么填

只要对方提供的是**「OpenAI 兼容」接口**（绝大多数都提供），就按同样的三格填：

| 服务 | 模型 ID | Base URL |
|---|---|---|
| **DeepSeek** | `deepseek-chat` | `https://api.deepseek.com` |
| **火山方舟** | `ep-` 开头的接入点 ID | 留空（默认就是它） |
| 其它 | 对方给的模型名 | 对方给的地址 |

> 想换模型，**只要改这三个格子就行**，不用改任何代码。

### 5.5 验证真的接上了

关掉设置面板，看右上角：

- 原来的橙色 `DEMO 模式...` 徽章，变成了 **`deepseek-chat`**。

这时候再在输入框里提问，老师就是真 AI 了。**故意答错一次试试**——它会追问你，而不是直接告诉你答案。

## 常见问题（照着排查）

### ❓ 1. `'python' 不是内部或外部命令`

Python 没装，或者装的时候没勾 **Add to PATH**。看第 1 步 1.2 节的警告。

### ❓ 2. `[X] 启动失败：端口 8787 已经被占用`

意思是**你已经开着一个了**（可能就在另一个黑窗口里）。

- 想关掉旧的：找到那个窗口，按 **Ctrl + C**；
- 想同时开两个：换一个端口，例如在命令行里先输入 `set PORT=8788` 再输入 `python run.py`，然后浏览器访问 `http://127.0.0.1:8788`。

### ❓ 3. 浏览器显示「无法访问此网站」

- 检查那个黑窗口是不是被你关掉了（关掉服务就停了，重新双击 `启动.bat`）；
- 检查地址有没有输错：是 `http://127.0.0.1:8787`，注意是 **http**，不是 https。

### ❓ 4. 页面能打开，但右上角一直是橙色的 DEMO 模式

说明密钥没配上。回到 ⚙ 设置：

- 三个格子是不是都填了？（Base URL 那格也别空着）
- 点「测试模型连接」看看报什么错；
- 填完有没有点 **保存**？

### ❓ 5. 测试连接报 `401` / `invalid api key`

密钥不对。常见原因：复制时漏了头尾、或者里面有空格。**重新复制一次**，粘贴后检查一下首尾。

### ❓ 6. 测试连接报 `404` / `model not found`

**模型 ID** 写错了。DeepSeek 要填 `deepseek-chat`（注意是短横线）。用火山方舟的话，填的是 `ep-` 开头的接入点 ID，不是模型名字。

### ❓ 7. 测试连接一直转圈 / 转很久后失败

网络问题。检查能不能正常上网；公司/学校网络如果有代理，可能要单独配置。

### ❓ 8. 黑窗口里出现一堆红色报错

把**整个窗口的内容复制下来**发给我。窗口里右键 → 全选 → 复制，或者在窗口标题栏右键 → 编辑 → 全选 → 复制。

### ❓ 9. 想确认文件有没有坏

双击 `自检.bat`。最后一行是 `OK` 就没问题；如果是 `FAILED`，把内容发我。

## 想让同学也能用（局域网共享）

默认只有你自己的电脑能访问。要让你和同学在**同一个 WiFi** 下一起用：

**1. 换成对外监听的模式启动**

在命令行里：

```
cd /d D:\academic-galgame-agent\python
set HOST=0.0.0.0
python run.py
```

**2. 查你自己的 IP 地址**

再开一个命令行窗口，输入：

```
ipconfig
```

找到 **IPv4 地址**，类似 `192.168.1.23`。

**3. 告诉同学访问**

让他们在浏览器里打开：

```
http://192.168.1.23:8787
```

（把 IP 换成你自己的）

> ⚠️ **注意几件事**：
> - 第一次这样启动时，Windows 可能会弹出防火墙提示，要点 **允许访问**；
> - **不要**在 `set HOST=0.0.0.0` 的同时用你自己的密钥填服务端配置 —— 那等于把额度开放给整个网络。
>   让同学各自在 ⚙ 设置里填**他们自己的**密钥；
> - 你们各自的学习进度是分开的，互不干扰；但**关掉服务后进度会清空**（这是设计如此）。

## 如果你想把代码放到服务器上（进阶，现在不用做）

这个版本没有自带 Docker 配置。想长期挂在服务器上，思路是：

1. 服务器装 Python 3.8 以上；
2. 把 `python` 文件夹传上去；
3. 用 `HOST=0.0.0.0 PORT=8787 python run.py` 启动；
4. 用 nginx 之类做反向代理 + HTTPS。

## 卡住了怎么办

把下面三样发给我，我能快速定位：

1. **你做到第几步**；
2. **黑窗口里的完整内容**（右键 → 全选 → 复制）；
3. **浏览器里看到什么**（报错的话，截图或把文字复制出来）。

如果页面本身有问题，再按 **F12**，切到 **Console** 标签，把红色报错也一起发来。
